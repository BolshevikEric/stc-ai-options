# STC AI Options

一个 SillyTavern(酒馆)UI 扩展:利用 AI 根据剧情自动生成下一步行动选项,渲染在聊天末尾,点击填入输入框继续对话。基于 SillyTavern 1.18.0 开发。

![license](https://img.shields.io/badge/license-AGPL--3.0-blue)

## 功能

- **AI 选项生成**:提取最新一条 AI 发言,通过内置多段式消息管道(身份锚定 + 前置创作自由对话 + 规则/世界书 + 剧情材料 + 交接确认 + 末尾 JSON 交付约束)发送给 AI 生成选项;点击填入输入框,「换一批」重新生成;AI 回复结束后自动生成(可关)
  - 可配置:生成规则与要求(数量、视角、字数与风格等均在规则编辑区直接调整,支持 `{{direction}}` 与酒馆全部原生宏)、独立「正则处理」模块(分「排除正则」与「提取正则」两个下级模块,均支持 `+` 新增、启用开关与拖拽排序,按从上到下顺序依次执行)
- **回应选项面板**:选项框渲染为独立面板 — 标题栏(标题 + 计数徽章 + 操作区)、编号选项卡片、底部状态栏;点标题或「收起」可折叠面板,点选项卡片会高亮
- **点击填充方式**:默认覆盖输入框;可在设置中开启「追加选项内容」,把选项追加到已有内容末尾(用换行分隔)
- **生成方向**:面板标题栏的「生成方向」按钮,点击展开输入行,输入本次生成选项的方向并确认后**立即按方向重新生成**;方向在会话内沿用(「换一批」与自动生成同样生效),留空确认即清除;规则中写了 `{{direction}}` 占位符则就地替换,未写则自动追加到规则末尾
- **世界书**:勾选哪些条目,生成选项时这些设定注入到规则区 `<world_info>` 块;书级复选框三态:全选 ✓ / 部分选中 —;列表默认收起,点标题右侧展开图标才加载并列出
- **AI API**:默认跟随酒馆主 API;也可配置自定义 OpenAI 兼容接口,带「测试连接」
- **插件主题**:选项框外观可切换(跟随酒馆 / 深色 / 浅色)
- **响应式布局**:适配 PC 与手机端
- **选项跟随消息**:选项写在「生成它时最新那条 AI 消息」的 `extra` 里,酒馆切换 swipe 分支时会自动把当前分支的 `extra` 镜像到 `swipe_info[id].extra`、切回来再克隆回 `extra`,因此每个分支各自独立;刷新页面、切换聊天、切换分支都会恢复该分支的选项,被编辑过的分支自动失效;每个聊天保留条数可设(默认 10 条,1–50)

## 安装

在酒馆顶栏打开「扩展」面板 → **Install extension** → 粘贴仓库地址:

```
https://github.com/BolshevikEric/stc-ai-options
```

或手动克隆到 `public/scripts/extensions/third-party` 后刷新页面。

## 使用说明

1. 魔法棒菜单 →「聊天选项」,确认已启用
2. 与 AI 对话,回复结束后自动生成选项(也可点「生成选项 / 换一批」手动触发)
3. (可选)点「生成方向」输入本次生成方向,确认后选项会朝该方向生成;留空确认即清除方向
4. 点击选项填入输入框,可编辑后发送(默认覆盖;开启「追加选项内容」后追加到已有内容末尾)
5. (可选)在设置里点世界书标题右侧展开图标,再勾选需要的世界书条目

### 设置项

| 设置 | 说明 |
|---|---|
| 启用选项框 | 总开关 |
| 追加选项内容 | 关闭:点击选项覆盖输入框;开启:追加到已有内容末尾(换行分隔) |
| 记住选项 | 开启:选项跟随 AI 消息分支存储,刷新页面 / 切换聊天 / 切换 swipe 分支后自动恢复 |
| 最多保留消息条数 | 配合「记住选项」,控制每个聊天保留多少条带选项的消息(1–50,默认 10);超出后更老的整条清除,调小会立即裁剪已存数据 |
| AI 回复后自动生成 | 关闭后仅手动触发 |
| 生成规则与要求 | 编辑选项的数量、视角、字数与风格等要求;`{{direction}}` 为生成方向(未设置时替换为空);支持酒馆全部原生宏(`{{char}}`/`{{user}}`、`{{persona}}`、`{{description}}`、`{{scenario}}`、`{{time}}` 等) |
| 提示词 | 独立折叠模块,可查看并自定义剩余 7 段请求消息(身份锚定、前置破限 User/Assistant、核对请求、确认回复、提交指令、末尾输出规则),支持一键恢复默认 |
| 正则处理 | 独立折叠模块,分为「排除正则」(移除匹配内容,不发给 AI)与「提取正则」(从剩余内容逐级抽取匹配片段);两个下级模块均支持 `+` 新增、启用开关、拖拽排序,按从上到下顺序依次执行 |
| 世界书 | 默认收起,点标题右侧展开图标才列出;勾选要附带给 AI 的条目;条目内同样支持原生占位符;书级复选框:全选 ✓ / 部分选中 — |
| AI API | `跟随酒馆主 API`(默认)或自定义 OpenAI 兼容接口 |
| 插件主题 | 跟随酒馆 / 深色 / 浅色 |

## 开发

- 目录:`index.js` + `settings.html` + `style.css` + `manifest.json`
- 发版需递增 `manifest.json` 里 `js` / `css` 的 `?v=` 参数,防止客户端缓存旧代码
- 官方扩展开发文档:<https://docs.sillytavern.app/for-contributors/writing-extensions/>
